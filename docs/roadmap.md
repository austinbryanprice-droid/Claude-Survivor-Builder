# Roadmap

About thirty small draft PRs cover Phases 0 to 6 plus a look spike (Phase 4 grew from three to eight and Phase 5 from three to thirteen as their parts took shape). Each PR keeps CI green before it leaves draft, and each visual PR carries screenshots from headless Chromium. The phases come from spec section 15.

Two side threads can start once Phase 2 lands, because they live in their own folders: the model generator, which feeds PRs 5d and 5f to 5h, and the audio synth, which feeds PR 6c. Austin's hands-on checks come at the end of Phases 1, 3, 4 and 6, plus a look at the look-spike screenshots. The look spike's frame-rate run so far was on a high-end laptop (an RTX 4090 Laptop at a 200 Hz display cap), so no mid-range dedicated GPU has been measured yet ([art-direction](art-direction.md#first-real-measurement)). The game page's own `?bench=1` has flown the same valley since Phase 2b, so the next hands-on run is the game page's, and it is the one to repeat after each Phase 2 meshing change.
