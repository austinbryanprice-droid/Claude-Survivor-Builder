Two side threads can start once Phase 2 lands, because they live in their own folders: the model generator, which feeds PR 5b, and the audio synth, which feeds PR 6c. Austin's hands-on checks come at the end of Phases 1, 3, 4 and 6, plus a look at the look-spike screenshots. The look spike's frame-rate run so far was on a high-end laptop (an RTX 4090 Laptop at a 200 Hz display cap), so no mid-range dedicated GPU has been measured yet ([art-direction](art-direction.md#first-real-measurement)). The game page's own `?bench=1` has flown the same valley since Phase 2b, so the next hands-on run is the game page's, and it is the one to repeat after each Phase 2 meshing change.
