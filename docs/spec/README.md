# Spec package (text only)

These files are the owner's original design package for Ashbound Outpost, kept verbatim so every contributor and every coding agent works from the same source. Do not edit them to record new decisions; add those to [`../decisions.md`](../decisions.md).

- `SPEC.md`: the primary specification. Sections 1 (non-negotiables) and 14 (scope guardrails) are locked.
- `notes/`: supporting notes on the multiplayer messages, economy and wave examples, and the bevel approach.
- `CAPTIONS.md`: captions for the eight visual references.

The spec mentions a `references/` folder of images. Those are third-party screenshots, so they are not part of this repository. [`../art-direction.md`](../art-direction.md) describes the look they set in words.
